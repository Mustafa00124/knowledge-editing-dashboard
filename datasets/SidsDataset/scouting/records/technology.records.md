## Changes from the scouting and why

- **0001 Linux:** every prompt says "the Linux kernel" (review fix; Stallman's
  GNU/Linux claim concerns the OS, never the kernel). Kept rather than swapping
  in the JavaScript backup. The unreproducible Wikipedia quote ("lack of a
  working kernel") is not used; the Linux kernel article's "The kernel was
  created by Linus Torvalds in 1991" and the Linux lead are used instead.
  Q1 is now the inverse query ("Did Stallman create the Linux kernel?") rather
  than a functional one, since `created_by` is not functional.
- **0002 Web:** kept as scouted; new `invented_by` relation (the edit's
  statement reads "was invented by"); far query changed to a non-technology one.
- **0003 Unix:** cites the Bell Labs facilities-list row (review fix); notes
  the New Brunswick move (also NJ). **Added a third world (w3)** and a third
  factual premise ("Bell Labs developed Unix at its Murray Hill
  headquarters"): Bell Labs ran several sites (one in North Andover, MA), so a
  model can keep "at Bell Labs" and "HQ in NJ" and move only the site. Because
  of w3 the premise-route query asks "the town where Unix was originally
  developed" (MA in all three worlds) rather than the scout's "the research
  laboratory" (which a w3 model could read as Bell Labs, HQ in NJ). Scout's Q2
  "Was Unix first developed in New Jersey?" (a functional reading on a relation
  that chains into states) replaced by "same state as Harvard University?".
- **0004 Java -> replaced by BASIC (NH -> VT).** Java (and the PostScript
  backup the review preferred) rest on "a product is developed in its
  developer's headquarters state", a default, not a definition: a world where
  Sun/Adobe developed it at an out-of-state office keeps the company's HQ and
  makes the premise-route query ("state of the company that developed X")
  indeterminate. BASIC was built on one campus (Dartmouth, Hanover NH), so the
  combining rule is location transitivity and holds in every world.
- **TBox (all new on this branch).** Main's technology TBox items were
  "designated category" panel items, unusable for the new/well-known member
  design. Rules chosen for no real exceptions and members whose class
  membership is not in their name. Rejected: Debian-based -> .deb (R2: ".deb"
  is read off "Debian"), first-generation -> vacuum tubes (definitional
  converse, and ENIAC also had 6,000 relays), C family -> braces (Wikipedia's
  list includes Nim, Ruby, C shell), Chromium -> Blink (Chrome on iOS),
  Office Open XML -> ZIP (Flat OPC).
- **RBox (all new):** every edit changes or removes a property that holds
  (coordinator's rule): transitivity removed (`released_after`), subproperty
  removed (`successor_of`), asymmetry changed to symmetry (`is_subdomain_of`),
  inverse replaced (`created_by`). An earlier draft of 0011 added
  functionality to `written_in`; it was re-picked because its delete would
  remove a negative original. Deletes of 0011 and 0012 rephrase the instances
  around the original property.

## Worlds dropped

- 0001 / 0002 birth-country queries: the route "the kernel/Web was created by
  a Finn/an English scientist" contradicts Stallman's/Cerf's birthplace; not a
  world (determinate). In the deletes, that description is treated as the same
  fact as the deleted one.
- 0003 / 0004: the site/college-in-state rule is definitional (location
  transitivity), never a world.
- TBox: no exception worlds (rules have no real exceptions).

## Remaining doubts

- **0004 BASIC derivability `likely`** is the weakest rating: no exact
  statement of "BASIC was developed in New Hampshire" in Dolma, but sampled
  co-occurrences carry the state through Dartmouth's address ("at Dartmouth
  College in Hanover, New Hampshire"), and the BASIC article mentions the NH
  historical marker. Premise 1 is also only moderately frequent ("BASIC was
  developed at Dartmouth" 12).
- **0003 premise 3** ("Bell Labs developed Unix at its Murray Hill
  headquarters") is claimed stored but is stated less often than the others;
  its w3 is the edge world. w1 (Unix not at Bell Labs) is strained.
- **0001 R2:** "Linux" is named after Linus; it hints at the original answer's
  first name. JavaScript -> Andreessen remains as a backup.
- **Description worlds (0001 w2, 0002 w2)** are the weaker hypotheses: the
  description almost always appears next to the name.
- **TBox well-known members:** w1 (member leaves the class: Linux not
  Unix-like, WordPress not GPL, F# not ML, macOS not Unix-like) is the README's
  tarantula pattern but strains firm membership facts. macOS's LF is stated by
  name less often than the class rule ("macOS uses LF" 3), so 0008 w1 is weak;
  a z/OS UNIX edge case (EBCDIC newline) is noted.
- **0006 plausibility:** "GPL programs are proprietary" is clearly false but
  only weakly plausible.
- New relations (`created`, `invented_by`, `maintains`, ...) may collide with
  other writers' additions at merge.
